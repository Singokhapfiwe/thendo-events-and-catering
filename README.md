# thendo-events-and-catering
responsive and glamorous website for thendo events
Tendo Events and Catering

Project Overview

Tendo Events and Catering is a responsive event planning and catering website created to present the services offered by Tendo Events and Catering in a professional, modern, and luxurious way.

The website was designed to provide visitors with information about the company, its services, previous events, and ways to make contact. The project focuses on creating an attractive and user-friendly experience while keeping the website easy to navigate across different screen sizes.

Purpose of the Website

The main purpose of this website is to:

- Introduce Tendo Events and Catering.
- Showcase the company's event planning and catering services.
- Display images and examples of events through the gallery.
- Provide information about the company.
- Give visitors a way to contact the business.
- Create a professional online presence for the business.

Website Pages

The website contains the following main pages:

Home Page

The home page introduces Tendo Events and Catering and provides an overview of the business. It also provides navigation to the other sections of the website.

About Page

The About page provides information about Tendo Events and Catering, including the company's identity, purpose, and approach to events and catering.

Services Page

The Services page presents the different services offered by the business, helping visitors understand what they can expect when using Tendo Events and Catering.

Gallery Page

The Gallery page displays images related to events and catering, allowing visitors to visually explore the type of work and experiences provided by the business.

Contact Page

The Contact page provides visitors with a way to get in touch with Tendo Events and Catering.

Technologies Used

The website was developed using:

- HTML5 – Used to create the structure and content of the website.
- CSS3 – Used for styling, layout, colours, spacing, typography, responsiveness, animations, and the overall visual design.
- JavaScript – Used to add interactive functionality to the website.
- Visual Studio Code – Used as the development environment.
- Git and GitHub – Used for version control and hosting the project repository.
- GitHub Pages – Used to publish the website online.

Development Process

The website was developed by first creating the basic HTML structure for the different pages. The content and page sections were then organised to create a consistent website structure.

CSS was added and developed to improve the visual presentation of the website. A new styling approach was implemented to create the luxurious dark-themed appearance and provide consistency across the pages.

Images were added to support the content and improve the visual presentation of the website.

JavaScript was also included where interactive functionality was required.

The website was tested locally during development using Visual Studio Code and Live Server. After the project was completed, the files were uploaded to GitHub and GitHub Pages was used to publish the website online.
